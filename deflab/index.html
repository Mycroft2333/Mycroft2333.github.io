Symmetry Defect Generator

Pure front-end local tool for CIF files. It expands the structure using symmetry operations found in the CIF, groups symmetry-equivalent sites for a chosen element, and generates vacancy or substitution defect structures, with optional supercell expansion and CIF/POSCAR export, entirely in your browser.

No Python No backend Runs locally in your browser

Notes: this single-file version first uses symmetry operations explicitly present in the CIF. If the CIF only provides identity/P1 symmetry, it will additionally try to infer symmetry from the lattice metric and exact atomic coordinates. This fallback works well for many orthogonal cells, but it is still not as general or as robust as a full crystallographic symmetry engine. Defect structures are exported as P1 CIF and/or POSCAR; when a supercell is requested, the defect is placed in the first translational image of the chosen inequivalent site.
