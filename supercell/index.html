  1. Upload or paste a CIF/POSCAR, then click Parse structure.
  2. Set the supercell size and click Build supercell.
  3. For partial-occupancy CIFs, click Generate rules from partial occupancy.
  4. Click Preview rules to check integer site counts.
  5. Select a generation mode and energy ranking method, then export CIF/POSCAR files.
target 支持元素名，例如 Fe；也支持 partial site tag，例如 P1。自动生成规则时优先使用 P1/P2，避免误替换同元素的 full-occupancy 位点。 The target can be an element, e.g., Fe, or a partial-site tag, e.g., P1. Auto-generated rules use P1/P2 tags to avoid replacing full-occupancy sites of the same element.

模式建议： Random 用于快速候选；Enumerate small 用于小组合数；SQS-like 用于让掺杂/空位更分散。Light symmetry 是轻量去重，不等价于完整 spglib/supercell 对称枚举。 Mode guide: Random is for quick candidates; Enumerate small is for small combinatorial spaces; SQS-like promotes dopant/vacancy dispersion. Light symmetry is a lightweight deduplication method, not full spglib/supercell symmetry enumeration.
Ewald-like 是浏览器内点电荷近似，用于候选排序，不等于 DFT 能量。α=0 时自动估算。非电中性体系会使用均匀背景修正。若希望氧空位按有效正电缺陷排序，可把 Vac:0 改为 Vac:+2。 Ewald-like ranking is a point-charge approximation for screening only, not a DFT energy. α=0 enables automatic estimation. A uniform-background correction is used for non-neutral cells. To treat oxygen vacancies as effective positive defects, set Vac:+2.
